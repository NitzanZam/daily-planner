# התוכנית שלי — לוח זמנים לילד

אפליקציית drag & drop שבה הילד משבץ פעילויות ביום שלו, בתוך מגבלות שההורה מגדיר.
בנויה למגע (טאבלט), ללא טקסט שצריך לקרוא, ונשמרת מקומית על המכשיר.

## הרצה מקומית

```bash
npm install
npm run dev
```

`npm run dev` מאזין גם לרשת המקומית, כך שאפשר לפתוח את הכתובת `http://<ה-IP-של-המחשב>:5173`
בדפדפן של הטאבלט ולראות שינויים בזמן אמת.

## העלאה ל-GitHub ומשם ל-Vercel

```bash
git init
git add .
git commit -m "planner v1"
git branch -M main
git remote add origin git@github.com:<המשתמש>/<הריפו>.git
git push -u origin main
```

ב-Vercel: **Add New → Project → Import Git Repository**, לבחור את הריפו ולאשר.
Vercel מזהה Vite לבד (build: `npm run build`, output: `dist`) — אין מה להגדיר.
מכאן כל `git push` ל-main מייצר deploy חדש אוטומטית.

## על הטאבלט

לפתוח את הכתובת ב-Safari ← כפתור השיתוף ← **הוסף למסך הבית**.
מכיוון שיש manifest ו-service worker, האייקון נפתח במסך מלא בלי סרגלי דפדפן,
והאפליקציה עובדת גם בלי אינטרנט (אחרי טעינה ראשונה אחת).
כדאי גם לנעול את מסך הטאבלט על מצב לרוחב.

## מה לשנות

הכול בראש `src/DayPlanner.jsx`:

| הגדרה | מה היא קובעת |
|---|---|
| `DAY_START` / `DAY_END` | טווח השעות שהציר מציג |
| `SLOT` / `SLOT_H` | רזולוציית הזמן וגובה רבע שעה בפיקסלים |
| `SCREEN_BUDGET` | תקציב המסך ברבעי שעה (4 = שעה), מוצג ככוכבים |
| `FIXED` | הבלוקים הנעולים. `days: [1, 3]` = הבלוק מופיע רק בימים אלה (0 = ראשון) |
| `ACTIVITIES` | מלאי הפעילויות. `min` = מינימום רבעי שעה, `must` = חובה, `single` = פעם אחת ביום, `screen` = נספר בתקציב, `after: "hw"` = מותר רק אחרי שהפעילות ההיא הסתיימה |

## הערות

- השמירה היא `localStorage` לפי תאריך — כלומר לכל מכשיר התוכנית שלו, ויום חדש מתחיל ריק.
  אם תרצה לראות את התוכנית שלו גם מהטלפון שלך, זה כבר מצריך שרת (למשל Vercel KV).
- ה-URL של Vercel פתוח לכל מי שמכיר אותו. הגנת סיסמה על deployment היא פיצ'ר בתוכנית בתשלום;
  חלופה זולה היא שער הורה פשוט בקוד.
