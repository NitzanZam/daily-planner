# התוכנית שלי — לוח זמנים לילד

אפליקציית drag & drop שבה הילד משבץ פעילויות ביום שלו, בתוך מגבלות שההורה מגדיר.
בנויה למגע (טאבלט), ללא טקסט שצריך לקרוא, ונשמרת מקומית על המכשיר.

## הרצה מקומית

```bash
npm install
npm run dev
```

`npm run dev` מאזין גם לרשת המקומית, כך שאפשר לפתוח את הכתובת `http://<ה-IP-של-המחשב>:5173`
בדפדפן של הטאבלט ולראות שינויים בזמן אמת.

## העלאה ל-GitHub ומשם ל-Vercel

```bash
git init
git add .
git commit -m "planner v1"
git branch -M main
git remote add origin git@github.com:<המשתמש>/<הריפו>.git
git push -u origin main
```

ב-Vercel: **Add New → Project → Import Git Repository**, לבחור את הריפו ולאשר.
Vercel מזהה Vite לבד (build: `npm run build`, output: `dist`) — אין מה להגדיר.
מכאן כל `git push` ל-main מייצר deploy חדש אוטומטית.

## על הטאבלט

לפתוח את הכתובת ב-Safari ← כפתור השיתוף ← **הוסף למסך הבית**.
מכיוון שיש manifest ו-service worker, האייקון נפתח במסך מלא בלי סרגלי דפדפן,
והאפליקציה עובדת גם בלי אינטרנט (אחרי טעינה ראשונה אחת).
כדאי גם לנעול את מסך הטאבלט על מצב לרוחב.

## שני מסכים

**מסך הילד** הוא מה שנפתח תמיד: ציר היום, הבלוקים הנעולים, ומלאי האריחים לגרירה.

**מסך ההורה** נמצא מאחורי ה-⚙️ בפינה, ומוגן בקוד בן 4 ספרות שנקבע בכניסה הראשונה.
משם אפשר לשנות הכול בלי לגעת בקוד:

| קטע | מה אפשר לשנות |
|---|---|
| גבולות היום | שעת ההתחלה והסיום של הציר (שעות עגולות) |
| כללים | תקציב המסך ברבעי שעה, ואורך מקסימלי לפעילות |
| בלוקים קבועים | הוספה, מחיקה, אימוג'י, שם, שעות, ובאילו ימים בשבוע הבלוק מופיע |
| פעילויות | הוספה ומחיקה, אימוג'י, שם, צבע, אורך התחלתי, ודגלי חובה / פעם ביום / נחשב מסך / רק אחרי פעילות אחרת |

שני דברים שהמסך שומר עליהם בשבילך:

- בלוק קבוע שיוצא מגבולות היום או מתנגש באחר מסומן באדום **לפני** השמירה, כדי שלא ייעלם בשקט.
- אם שינוי הגדרות הופך בלוק בתוכנית של הילד ללא חוקי (למשל הורדת תקציב המסך),
  הבלוק יורד והילד מקבל הודעה — במקום תוכנית שבורה.

### מה עוד בקוד

`src/settings.js` מחזיק את ברירות המחדל (`DEFAULTS`) ואת שכבת הבדיקה שמוודאת
שהגדרה פגומה לא מפילה את מסך הילד. `SLOT` ו-`SLOT_H` שם — רזולוציית הזמן
וגובה רבע שעה בפיקסלים — והם היחידים שנשארו קבועים.

## הערות

- השמירה היא `localStorage` לפי תאריך — כלומר לכל מכשיר התוכנית שלו, ויום חדש מתחיל ריק.
  אם תרצה לראות את התוכנית שלו גם מהטלפון שלך, זה כבר מצריך שרת (למשל Vercel KV).
- גם ההגדרות נשמרות ב-`localStorage`, ולכן הן לכל מכשיר בנפרד. מה שתגדיר בטלפון שלך
  לא יגיע לטאבלט של הילד.
- ה-URL של Vercel פתוח לכל מי שמכיר אותו. קוד ההורה מגן על ההגדרות, לא על הכתובת עצמה —
  הוא נועד לעצור ילד סקרן, לא תוקף. הגנת סיסמה על ה-deployment היא פיצ'ר בתוכנית בתשלום.
